# ballest-cryt4x-plugin
CryT4x Test Plugin for Ballest

Adds clear balls to the Customize page through Cosmetic Kit:

- **Waage**: a balance scale with a gold and a silver ball in its pans
- **Dominus**: the Dominus car standing on the ground inside the ball
