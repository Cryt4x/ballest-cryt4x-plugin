# ballest-cryt4x-plugin
CryT4x Test Plugin for Ballest

Adds a clear ball to the Customize page through Cosmetic Kit:

- **Waage**: a balance scale with a gold and a silver ball in its pans

The Dominus ball moved to its own plugin, [ballest-dominus-ball](https://github.com/Cryt4x/ballest-dominus-ball).
